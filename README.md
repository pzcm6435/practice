# Hyunwoo Jung — Portfolio

Personal portfolio site. Single static HTML page, no build step.

**Live site:** https://pzcm6435.github.io/practice/

## Stack

- HTML + [Tailwind CDN](https://tailwindcss.com)
- Vanilla JS (scroll reveal, scroll progress bar, animated counters)

## Run locally

Just open `index.html` in a browser — no install or server needed.

## Deploy

Pushing to `main` updates the live site automatically via GitHub Pages
(Settings → Pages → source: `main` / `/`).
